Demostración de API Reactiva (WebFlux)

Ver Repositorio Ver Analisis
Flujo reactivo:

Tanto Tecnologías como Ventajas realizan 1 request inicial a la API reactiva diseña con Spring Web Flux.

Cada request mantiene una conexión SSE (Server-Sent Events) con la API reactiva que emite eventos) y los datos FLUYEN de a uno desde el backend hacia Angular.

Las tecnologías y ventajas se emiten cada 3 segundos y luego la conexión finaliza. Las métricas de memoria se emiten continuamente para mostrar el estado del servidor en tiempo real.

Puedes presionar cualquiera de los botones para ejecutar esa misma request {{ numberOfConcurrentRequests }} veces y comparar el comportamiento y rendimiendo en MB utilizados por la api.
